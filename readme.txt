High-performance e-commerce fitness brand theme for WordPress with native Shopify Buy Button and Storefront API compatibility.

== Description ==

Kinetix Athletics is an elite e-commerce brand theme tailored for fitness labels, gym apparel brands, strength gear companies, and sports nutrition lines.

Features:
* Native Shopify Buy Button & Storefront checkout integration
* Interactive slide-out cart drawer with dynamic Free Shipping Progress Meter ($75+ threshold)
* Quick-add size buttons (XS, S, M, L, XL, XXL) on product card hover
* Interactive color swatch picker with live label updates
* Athlete lookbook with clickable interactive gear hot-spot pins
* Asymmetrical Category Bento Grids (Men's Training, Women's Activewear, Gear & Belts, Recovery)
* 8 Pre-populated authentic fitness products included out of the box
* Includes matching Shopify Online Store 2.0 Liquid sections in `/shopify/` for direct Shopify deployment

== Installation ==

1. Upload the `kinetix-fitness` folder to the `/wp-content/themes/` directory.
2. Activate the theme through the 'Themes' menu in WordPress (`wp-admin/themes.php`).
3. Navigate to Appearance > Customize > Kinetix Brand & Shopify Settings to link your Shopify store domain.
4. Enjoy your new athletic brand store!
